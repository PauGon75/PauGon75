YOUR PORTFOLIO WEBSITE - START HERE
====================================

WHAT IS IN THIS FOLDER
  index.html   -> the content (text, sections, buttons)
  style.css    -> the look (colors, fonts, spacing)
  script.js    -> the behavior (popups, counting numbers, mobile menu)
  images/      -> your pictures go here

HOW TO SEE IT
  Double-click index.html. It opens in your browser. That's it.
  (Better: in VS Code, install the "Live Server" extension, right-click
  index.html and choose "Open with Live Server". It refreshes as you type.)

HOW TO EDIT
  1. Open the folder in VS Code (File > Open Folder).
  2. Open index.html and press Ctrl+F (Cmd+F on Mac).
  3. Search for "EDIT ME" - every place you should change has that note.
  4. Replace "Your Name", "you@example.com", the job texts, projects, etc.
  5. Save (Ctrl+S) and look at the browser.

CHANGE THE COLORS
  Open style.css. At the very top, change the hex colors in :root { ... }

PUBLISH IT FOR FREE (GitHub Pages)
  1. Create a free account at https://github.com
  2. Click "+" > "New repository".
     Name it exactly:  yourusername.github.io   (Public)
  3. On the new repository page click "uploading an existing file".
  4. Drag ALL the files and the images folder in (index.html, style.css,
     script.js, images). Click "Commit changes".
  5. Wait 1-2 minutes, then open https://yourusername.github.io

  To update later: open the file on GitHub, click the pencil icon,
  edit, and commit. Or upload the new version of the file again.
